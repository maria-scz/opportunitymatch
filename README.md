# OpportunityMatch

Finding educational opportunities shouldn't require searching through hundreds of websites.

## What it does
A web app that helps students discover scholarships, universities, and educational
opportunities relevant to them — instead of manually searching, the platform builds
a profile and recommends matches using a weighted scoring algorithm.

## Tech Stack
- **Frontend:** React🩵
- **Backend:** Node.js + Express💚
- **Database:** SQLite💙
- **Architecture:** REST API👩🏽‍💻

## Project Structure
client/   — React frontend
server/   — Express backend + database
